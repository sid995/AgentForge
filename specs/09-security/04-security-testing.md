# Security Testing

- Static analysis and dependency scanning on every change.
- Container image and IaC scanning.
- Secret scanning for commits and generated source.
- Admission-policy tests.
- Tenant-isolation integration tests.
- Authorization matrix tests.
- Malicious prompt and command corpus.
- Egress escape tests.
- Supply-chain and unsigned-image rejection tests.
- Periodic threat-model review after architectural changes.
