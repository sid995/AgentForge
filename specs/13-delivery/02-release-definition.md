# Release Definition

A releasable component includes:

- source commit.
- reproducible build inputs.
- image digest.
- SBOM.
- vulnerability result.
- signature and provenance.
- database migration compatibility.
- Helm/Kustomize version.
- changelog and operator impact.
- linked dashboards and runbooks.

A feature release is rejected when mandatory tests, security policy, compatibility checks, or documentation are incomplete.
