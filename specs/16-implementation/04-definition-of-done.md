# Definition of Done

A task is complete when:

- Acceptance criteria are met.
- Domain invariants and state transitions are explicit.
- API and event compatibility is preserved.
- Database migrations are safe and reversible where practical.
- Authorization and tenant isolation are tested.
- Duplicate commands and events are safe.
- Timeouts, retries, and failure classification are implemented.
- Metrics, logs, traces, and alerts are appropriate.
- Unit, integration, and relevant end-to-end tests pass.
- Security and dependency scans pass.
- Deployment configuration and runbooks are updated.
- An ADR records any significant new decision.
